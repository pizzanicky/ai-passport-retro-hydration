# 复古荧光终端喝水提醒

基于 FoloToy AI Passport 的社区应用，使用原创复古绿色终端界面和素材。身份页显示 `USER-01` 和原创复古卡通人物（未使用真人照片）；喝水页提供固定时段的喝水提醒与总提醒开关。

首页用上/下键选页面，确定键进入，长按确定键返回。喝水页没有待确认提醒时，短按确定键切换总提醒开关；提醒弹出时，短按确定键表示已经喝水，短按上键可立即关闭全部提醒。开关状态保存在设备上，没有已保存状态时默认开启；旧版间隔与工作日设置不再生效。每天本地时间 09:00–21:00 固定每 30 分钟提醒一次，从进入提醒时段或开启总开关时开始计时。每次提醒发出四声提示音，每声约 0.5 秒、声间约 0.2 秒。确认喝水后重新计 30 分钟；关闭开关会清除当前提醒，重新开启后重新计时。当前固件固定使用亚洲/上海时区（UTC+8）。30 秒未操作后背光关闭，即使仍有待确认提醒也一样。提醒状态会保留，任意按键可唤醒屏幕查看。

首次校时，在 SYSTEM 页按确定键启动蓝牙配网。手机使用名为 `蓝牙配网-FoloToy AI PASSPORT` 的小程序，选择 `BLUFI_Hydration`，输入 2.4 GHz Wi-Fi 凭据并等待校时。长按确定键结束配网。SYSTEM 页按下键清除已保存 Wi-Fi 凭据。时钟未同步前不会触发提醒；校时后 Wi-Fi 会关闭以降低耗电。

名为「AI 通行证」的出厂身份卡小程序需要出厂固件提供身份资料服务；它提示“未识别到通行证功能”时，不代表当前应用的 BLUFI 配网失败。请使用上面写明的独立配网小程序。新版固件只在本次开机完成 SNTP 校时后认可时间并启用提醒。
