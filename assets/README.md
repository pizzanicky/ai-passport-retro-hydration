# Assets

This directory stores reusable fonts, images, music, and sound effects, organized by asset type.

Keep each asset in the matching subdirectory and document its destination, naming, integration method, and source/license. Do not mix binary assets with Markdown documentation.

## Fonts

Store reusable font files and generated font sources in `fonts/`.

- Use descriptive names that include the family, weight, size, and format when relevant.
- Document the source, license, character range, conversion command, and expected destination.
- Check Flash and internal-RAM impact before adding a font; the ESP32-C3 has no PSRAM.
- Do not commit fonts whose license does not permit redistribution.

The badge UI uses `fonts/Rajdhani-Bold.ttf` from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/rajdhani), under the SIL Open Font License in `fonts/OFL-Rajdhani.txt`. `fonts/badge_font_16.c` and `fonts/badge_font_28.c` contain printable ASCII (U+0020–U+007E), generated with `lv_font_conv` 1.5.3 using `--bpp 2 --no-compress --format lvgl` and `--size 16` or `--size 28`. Regenerate with `--font assets/fonts/Rajdhani-Bold.ttf -r 0x20-0x7E --lv-font-name badge_font_<size> -o assets/fonts/badge_font_<size>.c`, along with those options. Both are compiled into the badge application from `main/CMakeLists.txt`.

## Music and sound effects

Store reusable music and sound-effect sources in `music/`.

- Document the source, license, sample rate, bit depth, channels, conversion command, and destination.
- Prefer 16 kHz, 16-bit mono PCM when it matches the current BSP audio path.
- Check Flash and internal-RAM cost before embedding audio; stream or chunk long recordings.
- Do not commit media without redistribution permission.
